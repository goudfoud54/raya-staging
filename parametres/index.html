🤖 Bot WhatsApp (panneau SAV)

Réservé super_admin / SAV Eatime. Génère un token bot, déploie l'instance Node.js (Railway/VPS), puis livre l'accès au client. Voir la doc interne dans le repo eatime-wa-bot.
📖 Procédure de déploiement (interne SAV)

1. Crée le token bot ci-dessus pour l'org du client.

2. Le code du bot est dans le dossier local eatime-wa-bot/ (à pousser sur GitHub interne Eatime).

3. Déploie sur Railway / Fly / VPS dédié avec :

  • SUPA_URL =
  • BOT_TOKEN = le token généré
  • Volume persistant sur /data pour la session WhatsApp

4. Connecte un numéro WhatsApp Business dédié (un par client idéalement) en scannant le QR dans les logs Railway.

5. Demande au client d'ajouter le bot à ses groupes WhatsApp, puis envoie !id dans chaque groupe → tu colles le JID dans la fiche Restaurant côté client.

6. Facture le pack installation (à définir avec commercial).
